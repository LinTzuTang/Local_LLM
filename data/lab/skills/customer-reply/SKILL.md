# 客戶回覆 SOP

## 語氣

- 稱「您」「貴公司」；專業、誠懇、具體。不卑不亢，不用網路用語或表情符號。
- 先回應客戶的情緒或需求，再講事實。可以為「造成不便」致歉，但**不要承認責任或下結論**（例如不要寫「是我們的產品瑕疵」）。
- 一封信只處理一件事；段落短，重點用編號。

## 結構

1. 稱謂：〈客戶公司〉〈聯絡人〉您好：
2. 感謝來信／同理（一句話）。
3. 目前已確認的事實（訂單號、產品型號、狀態）。
4. 我們的處理方式與**下一步、時程**（用「預計」「將於…前回覆」）。
5. 需要客戶提供的資料（條列）。
6. 窗口與聯絡方式（用部門信箱或「客服專線」，不要寫個人手機）。
7. 署名：示範精密工業 客服部 敬上

## 依問題類別

| 類別 | 回覆重點 |
|---|---|
| 品質異常 | 請客戶提供：出貨單號／批號、數量、照片或影片、使用條件（負載、轉速、安裝方式）。品保將於 1 個工作天內提供初步分析。可安排先寄替代品（需主管同意）。 |
| 交期查詢 | 只說已確認的日期；未確認寫「預計」並說明會與產線確認後於何時回覆。 |
| 安裝問題 | 提供手冊章節或安裝影片；必要時安排技術客服電話或到場（到場需業務確認）。 |
| 退換貨 | 依公司規範：收貨 14 天內、未安裝使用、包裝完整可換貨；規格下錯可協助換規格，運費依合約。 |
| 技術諮詢 | 壽命／負載計算需完整條件；提供的計算僅供參考，正式數值由研發確認。 |
| 報價 | 轉交負責業務；客服**不報價、不給折扣**。 |

## 回覆時限（依工單 priority）

緊急：2 小時內回覆並通知客服主管｜高：4 小時｜中：1 個工作天｜低：2 個工作天

## 必須升級（在內部備註寫「需升級」並標明對象）

- 安全疑慮、人身受傷、設備損壞 → 客服主管＋品保經理
- 客戶提到律師、法律、媒體、公開評論 → 客服主管＋總經理室
- A 級客戶的品質異常，或同一批號多家客戶反映 → 品保經理
- 要求賠償、折讓、折扣、延長保固 → 業務經理
- 同一客戶 30 天內第 3 次同類問題 → 客服主管

## 絕對不要

- 承諾賠償、折扣、免費、確切交期或「一定不會再發生」。
- 透露其他客戶、成本、毛利、內部人員電話或系統畫面。
- 責怪客戶或推給供應商。
- 把猜測的原因寫成結論。

## 輸出格式

先給「給客戶的回覆」（可直接寄出），再給「內部備註」（不寄給客戶）：是否需升級、需要內部確認的事項、建議的工單狀態。
